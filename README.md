# UCS420 Cognitive Computing — Assignment 2

Python data structures: lists, tuples, sets and dictionaries.

Roll number used throughout: **1024170242**

## Files

| File | Question |
| --- | --- |
| `q1_lists.py` | Lists — build `L` from the roll digits, append/insert/remove/pop, sort, slice, comprehension |
| `q2_tuples.py` | Tuples — max/min, reversing, searching, immutability error, `*` unpacking |
| `q3_random.py` | Seeded random list of 100 numbers — odds, evens, primes, most frequent |
| `q4_sets.py` | Sets — union, intersection, difference, symmetric difference, subset/superset, discard |
| `q5_dictionaries.py` | Dictionaries — rename key, add/update, `pop` vs `del`, iteration, merging, comprehension |

## Running

```bash
python3 q1_lists.py
python3 q2_tuples.py      # asks for a score to search
python3 q3_random.py
python3 q4_sets.py        # asks for a value to discard from A
python3 q5_dictionaries.py
```

`q3_random.py` seeds with the roll number, so the same 100 numbers come out on every run.
